# Tasky

A simple task manager built with Kotlin and Jetpack Compose (Material 3).

## Features
- Add, edit, complete, and delete tasks (swipe left to delete, with Undo)
- Priority levels (Low / Medium / High) with color indicators
- Categories: Personal, Work, Study, Health
- Due dates with a Material date picker, and overdue highlighting
- Smart filters: All, Today, Upcoming, Overdue, Done
- Live search across title, notes, and category
- Progress summary card with overdue count
- Offline persistence with Room
- Material 3 design, dynamic color (Android 12+), light and dark themes

## Tech
Kotlin, Jetpack Compose, Material 3, Room, ViewModel + StateFlow (MVVM)

## Run
Open in Android Studio (Koala or newer), sync Gradle, run on an emulator or device (API 26+).
